    <h1>Web Development Basics - Assignment 1</h1>

   <h2>1. Computer Networks</h2>
    <p>A network connects multiple devices to share data and resources.</p>
    <ul>
        <li><strong>LAN (Local Area Network):</strong> Covers a small area like an office, room, or home.</li>
        <li><strong>MAN (Metropolitan Area Network):</strong> Covers a town or city.</li>
        <li><strong>WAN (Wide Area Network):</strong> Covers a large geographical area, across countries or globally.</li>
    </ul>

   <h2>2. Internet</h2>
    <p>The global network of interconnected computers communicating via standardized protocols (TCP/IP).</p>

  <h2>3. Client-Server Architecture</h2>
    <p>A network architecture where clients (browsers/users) request resources, and servers provide responses.</p>
    <ul>
        <li><strong>Client:</strong> The device or web browser making a request (e.g., entering <code>www.youtube.com</code>).</li>
        <li><strong>Server:</strong> The central computer storing website files that responds to client requests.</li>
        <li><strong>Request & Response:</strong> Client sends a request to the server, and the server returns data (HTML, images, video).</li>
    </ul>

  <h2>4. IP Address (IPv4 vs IPv6)</h2>
    <p>A unique address that identifies a device on the internet.</p>
    <ul>
        <li><strong>IPv4:</strong> 32-bit numerical address format (e.g., <code>192.201.1.0</code>).</li>
        <li><strong>IPv6:</strong> 128-bit alphanumeric address format designed to replace IPv4 due to address exhaustion (e.g., <code>196:210:2:0</code>).</li>
    </ul>

  <h2>5. DNS (Domain Name System)</h2>
    <p>Translates human-readable domain names (like <code>www.youtube.com</code>) into computer-readable IP addresses.</p>

  <h2>6. Web Browser & V8 Engine</h2>
    <p>A <strong>Browser</strong> is software used to access websites on the <strong>WWW (World Wide Web)</strong>.</p>
    <p><strong>V8 Engine:</strong> Google's open-source high-performance JavaScript engine used inside Google Chrome to execute JavaScript code quickly.</p>

  <h2>7. IDE (Integrated Development Environment)</h2>
    <p>Software application providing comprehensive facilities to programmers for software development.</p>
    <ul>
        <li><strong>Example:</strong> VS Code (Visual Studio Code).</li>
        <li><strong>Reference Website:</strong> W3Schools (<code>www.w3schools.com</code>).</li>
    </ul>
